## <span style="color:#2da44e">🆕 新增 2026-07-05</span> 本项目文件概览

本项目仅包含以下三类 Excel 文件:

| 文件名 | 类型 | 说明 |
|--------|------|------|
| `ani-bangumi-type2-YYYY-MM-DD.xlsx` | 主数据文件 | 完整原始导出字段(73 列),按日期归档的全量动画条目数据 |
| `type2_subject_YYMMDD_vs_YYMMDD.xlsx` | 差异对比文件 | 相邻期次之间的差异记录(新增、删除、修改),命名格式为"新日期_vs_旧日期" |
| `ani-bangumi-type2-YYYY-MM-DD-template.xlsx` | 模板转换文件 | 在主数据文件基础上精简的 41 列模板,面向用户填写收藏信息 |

> 详细字段结构与示例见下方各章节。

## 数据来源说明

本数据集基于Bangumi开源Archive文档的条目(Subject)数据,提取type=2的动画类型条目,并转换为Excel格式。原始字段定义如下:

### 条目(Subject)字段定义

| Key | 含义 | 备注 |
|-----|------|------|
| id | 条目ID | 唯一标识 |
| type | 作品类型 | 1表示漫画,2表示动画,3表示音乐,4表示游戏,6表示三次元(本数据集仅包含type=2动画) |
| name | 条目名 | 原始名称(日文/英文名) |
| name_cn | 条目简体中文名 | 简体中文名称 |

| summary | 条目梗概 | 动画剧情概述 |
| nsfw | 是否为NSFW | Not Safe For Work,是否含有成人内容(布尔值) |
| date | 发行日期 | 动画发行日期 默认为开播日放送日 |
| favorite | 收藏状态 | 想看、看过、在看、搁置、抛弃 |

| 关联的动画ID | 与该动画相关的其他动画ID,有关联的动画ID时,series则为True | 提取自subject-relations.jsonlines |

## <span style="color:#2da44e">🆕 新增 2026-07-05</span> 差异对比文件说明

除主数据文件 `ani-bangumi-type2-*.xlsx` 外,本数据集还会周期性生成相邻期次之间的差异对比文件,用于追踪每周动画条目的增删改情况,辅助数据版本管理和增量分析。

### 文件命名规则

差异文件统一命名为 `type2_subject_YYMMDD_vs_YYMMDD.xlsx`,格式为"新日期_vs_旧日期"。例如 `type2_subject_260616_vs_260609.xlsx` 表示 2026-06-16(新)对比 2026-06-09(旧)的差异。

### 内容结构

差异 Excel 文件包含 6 个 Sheet（3 个原始 + 3 个模板转换版），每行表示一条发生变更的条目。

#### 原始 Sheet（73 列，PARSER_HEADERS 表头）

| Sheet 名 | 说明 |
|----------|------|
| **新增** | 新增条目列表，列结构与主数据文件 `ani-bangumi-type2-*.xlsx` 一致（共 73 列原始导出字段），便于直接复用主数据文件的解析逻辑 |
| **删除** | 删除条目列表，列结构同上 |
| **修改** | 修改条目列表，首列为"修改总结"（描述字段变化），后接 73 列原始导出字段 |

#### 模板转换 Sheet（41 列模板格式，后缀 `_模`）

| Sheet 名 | 说明 |
|----------|------|
| **新增_模** | 对"新增"Sheet 数据执行模板转换后的结果（列映射 + 标签分类 + 12 步清洗），41 列模板字段 |
| **删除_模** | 对"删除"Sheet 数据执行模板转换后的结果，41 列模板字段 |
| **修改_模** | 对"修改"Sheet 数据执行模板转换后的结果，首列为"修改总结"，后接 41 列模板字段 |

模板转换的逻辑与 `ani-bangumi-type2-*-template.xlsx` 完全一致（详见下方"模板转换文件说明"章节），即把 73 列原始字段经过列映射、标签分类（播出方式/原作标签/制片国家）、12 步数据清洗后，精简为 41 列模板字段。

#### Sheet 创建规则

数据为空时对应 Sheet 不创建，具体规则如下：

| Sheet | 创建条件 |
|-------|----------|
| 新增 / 新增_模 | 仅在有新增数据时创建 |
| 删除 / 删除_模 | 始终创建（即使为空也保留表头） |
| 修改 / 修改_模 | 仅在有修改数据时创建 |

### 具体示例:`type2_subject_260616_vs_260609.xlsx`

- 对比时间段: 2026-06-16(新)对比 2026-06-09(旧)
- 数据统计(引自同目录 `差异对比汇总报告.json`):
  - **type2_subject**: 新增 81 条、删除 0 条、修改 12546 条;旧数据 30079 条,新数据 30160 条,净变化 81 条。
  - **type2_subject-relations**: 新增 377 条、删除 19 条、修改 16 条;旧数据 81753 条,新数据 82111 条,净变化 358 条。
  - **type2_episode**: 无变化(新增/删除/修改均为 0)。
  - **全量合计**: 总新增 458 条、总删除 19 条、总修改 12562 条,净变化 439 条。

### 用途

- 追踪每周动画条目的新增、删除、修改情况
- 辅助数据版本管理和历史回溯
- 支持增量分析,无需对比完整 dump 即可获取变更明细

## <span style="color:#2da44e">🆕 新增 2026-07-05</span> 模板转换文件说明

主数据文件 `ani-bangumi-type2-*.xlsx` 字段较多(73 列),为方便个人收藏管理,提供精简后的模板文件。

### 文件命名规则

在主数据文件名后追加 `-template` 后缀,即 `ani-bangumi-type2-YYYY-MM-DD-template.xlsx`。

### 列结构

模板文件共 41 列,是面向用户填写的精简视图,混合三类列:

- **自动编号列**: 如"序列号"(自动生成)
- **用户填写列**: 如"是否看完""看完时间""开播季度""播出方式""原作标签""特点/印象""集号""系列""季数""系列集数""电影院""影厅""电影票存根""剧透/感言"等
- **数据来源列**: 从主数据文件映射,例如:
  - "开播日期" ← date 字段
  - "类别" ← platform 字段
  - "制作公司" ← infobox 中的"动画制作公司"
  - "名称" ← name_cn/name 字段
  - "标签/分级" ← meta_tags 字段
  - "完播日" ← infobox 中的"播放结束"
  - "集数" ← infobox 中的"话数"
  - "时长/分钟" ← infobox 中的"片长"
  - "Bangumi URL" ← URL 字段
  - 各 infobox 解析字段(制片国家、语言、类型、导演、音乐、人物设定、机械设定、原作、脚本、分镜、演出、原案、系列构成、在线播放平台)
  - "关联的动漫ID" ← subject-relations.jsonlines

完整的 41 列定义详见上方"Excel模板表头结构"章节。

### 与主数据文件的区别

| 项目 | 主数据文件 `ani-bangumi-type2-*.xlsx` | 模板文件 `ani-bangumi-type2-*-template.xlsx` |
|------|----------------------------------------|-----------------------------------------------|
| 列数 | 73 列(完整原始导出字段) | 41 列(精简视图) |
| 用途 | 数据分析、研究、完整存档 | 个人收藏记录、看完标记、评分填写 |
| 数据来源 | 主数据文件 `ani-bangumi-type2-*.xlsx` |
